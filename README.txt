คลังเจ๋งแจ๋ว — เว็บไซต์เงินทุนธุรกิจ
เวอร์ชันปรับปรุง: 25 กันยายน 2569

สิ่งที่เพิ่มในเวอร์ชันนี้
1. หน้าเข้าสู่ระบบด้วยอีเมล + รหัสผ่าน
2. ปุ่มสร้างบัญชีสำหรับ Firebase Authentication
3. ซิงก์ข้อมูลข้ามหลายเครื่องด้วย Firebase Firestore เมื่อใส่ Firebase Config แล้ว
4. แสดงสถานะคลาวด์บน Dashboard และมีปุ่มออกจากระบบ
5. เพิ่มเงินที่สามารถลงทุนได้ / เงินที่ใช้ส่วนตัวได้ / เงินยังไม่จัดสรร
6. เพิ่มหน้าต่าง “แบ่งเงินลงทุน / เงินส่วนตัว” พร้อมปุ่มยืนยัน และไม่ให้จัดสรรเกินเงินสด
7. เปลี่ยนมังกรจากอีโมจิเป็นมังกร SVG โทนแดง-ทอง พร้อมแอนิเมชัน
8. ยังมีพื้นหลังเช้า / กลางวัน / กลางคืน และเอฟเฟกต์เดิม

ทดลองใช้ก่อนเชื่อมคลาวด์
- เปิด index.html ใน Chrome/Edge
- ที่หน้าเข้าสู่ระบบ กด “ทดลองใช้ในเครื่องนี้”
- โหมดทดลองจะบันทึกข้อมูลเฉพาะเบราว์เซอร์เครื่องนั้น และไม่ซิงก์ไปเครื่องอื่น

เปิดใช้งานบัญชีจริงและซิงก์หลายเครื่อง
1. สร้างโปรเจกต์ใน Firebase Console
2. เปิด Authentication > Sign-in method > Email/Password
3. สร้าง Firestore Database
4. เปิด Project settings > General > Web app แล้วคัดลอก Firebase Config
5. เปิด index.html แล้วค้นหา “const firebaseConfig=”
6. แทนค่า YOUR_API_KEY, YOUR_PROJECT, YOUR_PROJECT_ID, YOUR_SENDER_ID และ YOUR_APP_ID ด้วยค่าจริงจาก Firebase
7. นำเว็บไซต์ขึ้น GitHub Pages / เว็บโฮสต์ที่ใช้งาน HTTPS
8. สร้างบัญชีจากหน้า “สร้างบัญชี” แล้วใช้อีเมล/รหัสผ่านเดียวกันบนเครื่องอื่น

Firestore Security Rules ที่แนะนำ
--------------------------------
เข้าสู่ Firebase Console > Firestore Database > Rules แล้วใช้แนวคิดสิทธิ์ดังนี้

 rules_version = '2';
 service cloud.firestore {
   match /databases/{database}/documents {
     match /users/{userId}/{document=**} {
       allow read, write: if request.auth != null && request.auth.uid == userId;
     }
   }
 }

กฎนี้ทำให้บัญชีหนึ่งอ่าน/เขียนข้อมูลของบัญชีตัวเองได้ และไม่เปิดให้บัญชีอื่นเข้าถึงข้อมูลของกันและกัน

โครงสร้างหลัก
- หน้าหลัก / Dashboard
- สินค้า / ไอดีเกม (หน้าต่างแยก)
- รายรับ - รายจ่าย (หน้าต่างแยก)
- บันทึกรายจ่าย
- สรุปรายงาน
- ตั้งค่าร้าน
- แก้ไขเงินทุน
- แบ่งเงินลงทุน / เงินส่วนตัว
- เข้าสู่ระบบ / สร้างบัญชี / ออกจากระบบ

หมายเหตุสำคัญ
- รหัสผ่านจริงจะถูกจัดการโดย Firebase Authentication ไม่ได้เก็บรหัสผ่านไว้ใน localStorage ของเว็บไซต์
- ไฟล์นี้เป็น Front-end ไฟล์เดียว แต่การซิงก์หลายเครื่องต้องมีบริการคลาวด์ เช่น Firebase และต้องใส่ Firebase Config ก่อน
- ค่า Firebase Web Config ไม่ใช่รหัสผ่านลับ แต่ Firestore Security Rules ต้องตั้งให้ถูกต้องเพื่อป้องกันข้อมูลของแต่ละบัญชี
